# 📈 Stock Market Analysis & Prediction (Tesla - TSLA)

🚀 End-to-End Data Analysis & Machine Learning Project

---

## 📌 Project Overview
This project analyses historical stock price data for Tesla (TSLA) and builds a machine learning model to understand trends and predict future price movements. The analysis includes data exploration, visualization, and predictive modeling.

---

## 🎯 Objective
- Analyse Tesla stock price trends
- Identify patterns in historical data
- Build a predictive model for stock movement
- Visualize key financial insights

---

## 📊 Dataset
- Stock: Tesla (TSLA)
- Data includes:
  - Date
  - Open Price
  - High Price
  - Low Price
  - Close Price
  - Volume

---

## ⚙️ Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 🔄 Project Workflow

1. Data Loading  
   - Imported stock dataset using Pandas  

2. Data Cleaning  
   - Converted date column  
   - Checked missing values  

3. Exploratory Data Analysis (EDA)  
   - Visualized stock price trends over time  
   - Analysed price fluctuations  

4. Feature Engineering  
   - Selected relevant features (Open, High, Low, Volume)  

5. Train-Test Split  
   - Split dataset for model training  

6. Model Training  
   - Linear Regression (for price prediction)  

7. Model Evaluation  
   - R² Score  
   - Mean Squared Error (MSE)  

---

## 🤖 Model Used

### 🔹 Linear Regression
- Predicts continuous values (stock price)  
- Establishes relationship between features and target (Close Price)  

---

## 📈 Results
- Model successfully captured overall trend of stock prices  
- Reasonable prediction accuracy using linear regression  


## 📌 Key Insights
- Stock prices show high volatility over time  
- Closing price is strongly influenced by opening price and market trends  
- Linear regression provides baseline prediction but may not capture complex patterns  

---

## ⚠️ Important Learning
- Stock data is time-series → requires advanced models for better accuracy  
- Linear regression is simple but limited for financial prediction  
- Feature selection is critical in financial datasets
